# 🖱️ The Clicker Hero
> 스팀 출시를 목표로 개발 중인 본격 클릭커 액션 게임!

## 🎮 게임 소개
**The Clicker Hero**는 단순한 클릭을 넘어 전략적인 업그레이드와 성장을 경험할 수 있는 게임입니다.

## 🛠️ 기술 스택
- **Engine:** Unity
- **Language:** C#
- **Platform:** PC (Steam)
